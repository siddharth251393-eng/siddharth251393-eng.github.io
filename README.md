# IndustryWire

**Business & Industry Intelligence** — an independent global publication concept with an Indian market perspective.

Live site: <https://siddharth251393-eng.github.io/>

IndustryWire is a static site hosted on GitHub Pages. It currently has no database, paid tooling, analytics, newsletter backend, checkout or published news stories. Research catalogue entries are clearly labeled proposed scopes, not completed reports. Read [README-FIRST.txt](README-FIRST.txt) before editing or publishing content.

## Pages

- Homepage and five sector pages
- Research concept catalogue with search and category filters
- Newsroom archive, currently empty until verified reporting is ready
- About, Contact, Editorial Policy, Corrections, Privacy and Terms
- Search page and reusable noindex article layout
- Ten source-linked editorial demonstrations, marked as samples and excluded from the newsroom feed and sitemap

## Local preview

Serve this folder with any static HTTP server and open the local address in a browser. No package installation or build step is needed.

## GitHub Pages

The repository is intended to publish from the `main` branch root using GitHub Pages. Canonical URLs, robots.txt and sitemap URLs use the existing `siddharth251393-eng.github.io` address.
